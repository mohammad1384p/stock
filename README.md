# stock — ربات سفارش زمان‌دار Exir

در ساعت مشخص (ساعت:دقیقه:ثانیه) شروع به ارسال درخواست ثبت سفارش به
`https://khobregan.exirbroker.com/api/v1/order` می‌کند و **۱۰ ثانیه** با فاصله‌ی
**۳۰۵ میلی‌ثانیه** (≈ ۳۳ درخواست) ادامه می‌دهد. پاسخ هر درخواست در ترمینال چاپ می‌شود.

## نصب
```bash
pip install -r requirements.txt
```

## اجرا
تعاملی (توکن، نماد، تعداد، قیمت و ساعت پرسیده می‌شود):
```bash
python exir_bot.py
```
با آرگومان:
```bash
python exir_bot.py -s IRO7TONP0001 -q 10 -p 6700 -t 08:44:59.700
python exir_bot.py -s وتوصا -q 10 -p 6700 -t 08:45:00 --token "<TOKEN>" --app-n "2018887747744.29964494"
```

| آرگومان | توضیح | پیش‌فرض |
|---|---|---|
| `-s` | نماد / نام / تگ یا ISIN (`insMaxLcode`) | پرسیده می‌شود |
| `-q` | تعداد | پرسیده می‌شود |
| `-p` | قیمت (ریال) | پرسیده می‌شود |
| `-t` | ساعت شروع `HH:MM:SS` یا `HH:MM:SS.mmm` | پرسیده می‌شود |
| `--side` | `buy` / `sell` | `buy` |
| `-d` | مدت ارسال (ثانیه) | `10` |
| `-i` | فاصله‌ی درخواست‌ها (میلی‌ثانیه) | `305` |
| `--token` | توکن لاگین (یا `EXIR_TOKEN`) | پرسیده می‌شود (مخفی) |
| `--auth-header` | هدری که توکن در آن می‌رود | `Authorization` (با `Bearer`) |
| `--cookie` | هدر cookie کامل (یا `EXIR_COOKIE`) | — |
| `--app-n` | هدر `x-app-n` (یا `EXIR_APP_N`) | — |
| `-H` | هدر اضافه `'name: value'` (قابل تکرار) | — |
| `--base-url` | آدرس کارگزاری | `https://khobregan.exirbroker.com` |
| `--tz` | منطقه‌ی زمانی ساعت (خالی = ساعت سیستم) | `Asia/Tehran` |
| `--no-stop` | بعد از سفارش موفق هم ادامه بده | توقف بعد از اولین موفقیت |
| `--now` | همین الان شروع کن (تست) | — |
| `--dry-run` | فقط نمایش، بدون ارسال | — |
| `-y` | بدون پرسیدن تأیید | — |

## توکن را از کجا بیاورم؟
در مرورگر وارد اکسیر شوید ← F12 ← تب Network ← یک سفارش (یا هر درخواست `api/v1/...`) را
انتخاب کنید ← در Request Headers مقدار `authorization` را بردارید و به `--token` بدهید.
اگر احراز هویت با کوکی است، مقدار `cookie` را به `--cookie` و مقدار `x-app-n` را به `--app-n` بدهید.

## نماد ← ISIN
- اگر ISIN (مثل `IRO7TONP0001`) بدهید مستقیم استفاده می‌شود.
- اگر نماد فارسی بدهید، اول در `symbols.json` و بعد در TSETMC جستجو و نتیجه در `symbols.json` ذخیره می‌شود.

## نکات
- زمان‌بندی بر اساس ساعت سیستم است؛ قبل از اجرا ساعت سیستم را همگام کنید. اختلاف تقریبی با ساعت سرور در شروع چاپ می‌شود.
- هر درخواست در یک thread جداگانه ارسال می‌شود تا کندی پاسخ‌ها فاصله‌ی ۳۰۵ms را به هم نزند.
- با پیش‌فرض، بعد از اولین پاسخ `orderSuccess` ارسال متوقف می‌شود (درخواست‌هایی که قبلاً فرستاده شده‌اند ممکن است ثبت شوند).
